# 页面与交互清单

## uni-app 用户端

| 页面 | 路由 | 核心操作 |
| --- | --- | --- |
| 身份登录 | `pages/login/index` | 选择演示身份；后续接入微信登录适配器 |
| 附近车位 | `pages/index/index` | 选择小区和时间、查看地图与车位列表 |
| 车位详情 | `pages/space/detail` | 查看公开详情、选择车辆、发起预约 |
| 预约结果与详情 | `pages/booking/detail` | 查看完整信息、取消、入场、离场、评价和投诉 |
| 我的预约 | `pages/orders/index` | 查看订单列表与状态 |
| 我的车辆 | `pages/vehicles/index` | 新增、查看、停用车辆 |
| 我的共享 | `pages/share/index` | 查看车位、发布或撤销时段、查看车位预约 |
| 车位登记 | `pages/share/edit` | 提交或修改车位并重新进入审核 |
| 我的 | `pages/profile/index` | 身份信息、认证状态、进入车主功能 |

底部导航固定为“找车位、订单、共享、我的”。登录页不展示底部导航。

## 管理后台

管理后台当前为单页工作台，左侧导航切换业务区，不依赖前端路由。

| 工作区 | 视图键 | 核心操作 |
| --- | --- | --- |
| 登录 | 未登录态 | 使用本地物业管理员演示身份 |
| 工作台 | `dashboard` | 待审核、进行中订单、未处理投诉摘要 |
| 小区管理 | `communities` | 新增和启停小区 |
| 车位审核 | `spaces` | 查询、审核通过、驳回 |
| 订单管理 | `bookings` | 查询全部订单和状态 |
| 投诉处理 | `complaints` | 解决或驳回投诉 |
| 审计日志 | `audits` | 查看敏感管理操作 |

管理后台采用左侧导航和表格为主，不使用移动端卡片布局替代表格。
