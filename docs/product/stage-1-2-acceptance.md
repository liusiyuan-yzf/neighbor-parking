# 阶段 1、2验收清单

- 基线版本：0.2.0
- 适用范围：产品设计与免费车位共享 MVP
- 明确排除：支付、退款、车位主结算、智能道闸和商业化计费

## 阶段 1：规则与设计

- [x] 产品角色、权限和首发范围有明确文档。
- [x] 用户端、车位主端和管理端页面清单完整。
- [x] 预约、取消、入场、离场、投诉和审核状态机明确。
- [x] REST API 通过 OpenAPI 描述，并与实现一致。
- [x] MySQL 数据库迁移脚本可从空库执行。
- [x] 隐私规则落实为“预约前模糊位置、预约后详细车位”。
- [x] 双重预约由服务端事务和数据库锁阻止。

## 阶段 2：免费共享 MVP

### 用户与认证

- [x] 开发环境可使用演示身份登录并获得 JWT。
- [x] 用户可以查看当前身份和认证状态。
- [x] 用户可以新增、查看和停用自己的车辆。

### 找车位与预约

- [x] 用户可以按小区和时间查询已审核、可预约的免费车位。
- [x] 未预约用户看不到完整车位编号和敏感入场说明。
- [x] 用户可以选择车辆创建预约。
- [x] 两个并发请求不能预约同一车位的重叠时段。
- [x] 用户可以查看订单、取消未开始订单、确认入场和确认离场。
- [x] 订单完成后可以评价，订单异常时可以发起投诉。

### 车位共享

- [x] 认证住户可以提交车位并等待审核。
- [x] 车位主可以查看和修改自己的车位。
- [x] 已审核车位可以发布一次性免费时段并撤销未预约时段。
- [x] 车位主可以查看自己车位产生的预约。

### 物业与平台管理

- [x] 管理员可以维护小区。
- [x] 管理员可以审核或驳回车位。
- [x] 管理员可以查询订单、投诉和审计日志。
- [x] 管理员可以受理和关闭投诉。
- [x] 敏感管理操作写入审计日志。

### 工程质量

- [x] Spring Boot 单元及集成测试通过。
- [x] uni-app TypeScript、H5 和微信小程序构建通过。
- [x] 管理后台 TypeScript 和生产构建通过。
- [x] Docker Compose 包含 MySQL、服务端和两个前端，配置结构与敏感变量占位检查通过。
- [x] GitHub Actions 覆盖后端测试、两个前端构建、依赖审计和部署配置校验。
- [x] 无密钥、真实个人信息、调试后门或默认生产密码进入仓库。
- [x] 完成代码审查并将全部变更推送 GitHub。
